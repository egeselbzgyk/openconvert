2 · Blocking startup errors (the only blocking screens)

a · converter speaks a different protocol version

OpenConvert can't start its converter

The app and its converter speak different versions of their protocol (the app expects 3, the converter answered 2). Converting now could produce wrong results, so nothing will run.

This usually means the installation is incomplete or was partly updated. Reinstalling OpenConvert 1.0.0 fixes it. Your EPUBs and settings are not affected.

b · bundled converter version differs from the app

The bundled converter doesn't match this app

This app is version 1.0.1, but the converter it found is version 1.0.0. They are shipped together and must be the same version, so nothing will run.

An update may have been interrupted. Install OpenConvert 1.0.1 again (on Linux via Flatpak: flatpak update org.openconvert.OpenConvert).
