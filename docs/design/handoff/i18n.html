Turkish checks: the dotted and dotless i survive because nothing uses text-transform ("İptal", "Yanıt vermiyor", "Tanılama"). The percent sign goes first (%62). Ordinals use a period ("Sırada (2.)"). The longest TR action, "Tanılama paketini dışa aktar", sets the width of the action row, and the row wraps instead of clipping.

3 · 200 % OS text size and the minimum window

Proposed minimum window: 720 × 520. Below 720 px the result's two action rows would stack into four lines, and below 520 px the expanded result no longer fits with the drop strip. At 200 % text everything scales, because every size is in rem. The queue column fills the width, and the list scrolls inside main while the header and drop strip stay visible.

Inside the queueArrow Up/Down moves between rows (roving tabindex), so 40 rows don't mean 40+ Tab stops. Enter or Space on a completed row toggles its result. Delete on a waiting row removes it. ImplementationDOM order is the focus order. The header is last in the DOM and drawn first with order:-1. There are no positive tabindex values.

5 · Screen reader annotations

Element / eventRole, label, live region
Drop zonegroup "Add PDFs. Drop files here or use Select PDF." The button: "Select PDF…". Drop results: polite "3 PDFs added to the queue" / "notes.docx skipped: not a PDF".
Queuelist "Queue, 3 files". Each item is labelled "file name, status", e.g. "moby-dick.pdf, Queued, number 2".
Stage changepolite live region (one per app): "the-wheels-of-chance.pdf: Reconstructing." Counts are not streamed; the progressbar has aria-valuetext "132 of 214 pages".
Completionpolite: "the-wheels-of-chance.pdf: Complete. Validation: passed with warnings, 2 warnings."
Invalidpolite: "araba-sevdasi.pdf: Complete. Validation: invalid. The file was saved."
Not respondingassertive, once: "moby-dick.pdf: Not responding." Then polite "…: Analyzing" if heartbeats return.
Cancelpolite: "Cancelling moby-dick.pdf…" → "moby-dick.pdf: Cancelled. No file was written."
Failuresassertive: "download (3).pdf: This file doesn't look like a valid PDF." Focus is never moved automatically.
Result panelthe expand button has aria-expanded and aria-controls. On expand, focus moves to the panel heading (the file name).
Page linksbutton "Go to page 34 in the preview". Disabled links have aria-describedby pointing to "No preview available".
Dialogsrole=dialog, aria-modal, labelled by the title. Focus opens on the safe button (Cancel), is trapped, and Esc closes. On close, focus returns to the button that opened it.
Startup errorsrole=alertdialog. Focus starts on "Copy details".

There is one polite region and one assertive region for the whole app, not one per row, so 40 jobs don't talk over each other. The heartbeat is never announced (aria-hidden).
