OpenConvert desktop UI: Stage 3 handoff

Direction 2b "Quiet workshop". Plain HTML + CSS custom properties, sized in rem, flexbox only. No :has(), container queries, subgrid or backdrop-filter. System fonts and Lucide (ISC) icons are the only assets, and nothing loads from the network. Class names map one-to-one to the planned Svelte 5 components.
