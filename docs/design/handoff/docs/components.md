# Component specs (direction 2b "Quiet workshop")

Each component maps 1:1 to a Svelte 5 component and a block in `oc.css`. Tokens come from `tokens.css`. Every interactive element shows the shared focus ring on `:focus-visible`: 2 px `--oc-focus`, 2 px offset, following the element's radius. Pointer targets are at least 24 × 24 px; buttons are 36–40 px high.
